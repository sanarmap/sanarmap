## Ce que vous pouvez faire

Copier, distribuer, utiliser, adapter les données, y compris dans un projet commercial.

## À condition de

- **Citer** : « SanarMap, d'après © contributeurs OpenStreetMap », visible près de la carte
  ou dans les crédits de votre application.
- **Partager à l'identique** : si vous publiez une base de données modifiée ou enrichie à partir
  de celle-ci, elle doit être sous ODbL elle aussi. Une carte, une image ou une app qui
  *utilise* les données n'a pas à être libre.
- **Garder ouvert** : pas de mesure technique qui empêche d'en reprendre les données.
